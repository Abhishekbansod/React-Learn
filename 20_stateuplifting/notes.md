State uplifiting :
State uplifting in React refers to the process of moving state from a child component to a common parent component. 
This is typically done to share the state between multiple child components or to manage the state in a centralized place.

=> Shared State: When multiple child components need to access or modify the same state, it's better to manage the state in their common parent

=> Data Consistency: Uplifting state ensures that all components relying on the state get the same, consistent data

=> Improved Control: The parent component can mediate updates to the state, improving maintainability and predictability.

=> Ensures consistent and synchronized state across components.
